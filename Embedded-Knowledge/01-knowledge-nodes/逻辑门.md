# 逻辑门

一句话：逻辑门是把输入电平按固定规则映射到输出电平的最小电路单元。

## 为什么存在

电路里只有电，没有数。要用电实现任何规则（如加法），必须有一种东西能把「输入什么电平」固定地变成「输出什么电平」。逻辑门就是这种「看输入、定输出」的最小零件。没有它，任何「规则表」都落不到电路上。

## 与、或、非

约定：有电=1，没电=0。

- **非（NOT）**：把信号翻面。输入 1 输出 0，输入 0 输出 1。
- **与（AND）**：两个输入都为 1 才输出 1（像两个开关串联）。
- **或（OR）**：任一输入为 1 就输出 1（像两个开关并联）。

## 为什么三者够搭出任何表（完备性）

三个角色配合，能一行一行拼出任意表：

- 非：负责选正反；
- 与：负责锁定唯一一行（给一行做一颗「探测器」）；
- 或：负责合并多行。

对每个「输出为 1」的行，用一串「与+非」做出只在该行命中的探测器，再把所有探测器「或」起来，整张表就被拼完。这个构造叫「与/或/非完备」。

## CMOS 物理层：为什么「反相型」门才是原生的

晶体管是电压控制的开关，分两种、导通条件相反：

- N 管：输入 1 才导通，把输出往下拉到 0；
- P 管：输入 0 才导通，把输出往上拉到 1。

由此，芯片里**天然、直接**能造的是反相型门——非、与非、或非：

- 与非门「输出 0」要两输入都 1 → 两个 N 管串联；「输出 1」要任一为 0 → 两个 P 管并联。4 管，天然匹配，不用反相。
- 「与门」要「输出 1 需两输入都 1」，但 P 管天生在输入 0 才导通，正好相反 → 必须先反相。所以与门 = 与非门 + 非门，6 管。

逻辑层上「与非 = 与 + 非」没错，但物理层上「与 = 与非 + 非」才成立。
