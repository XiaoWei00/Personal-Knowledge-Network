# 与非门

一句话：与非门（NAND）是只有两个输入都为 1 时才输出 0、其余都输出 1 的门，也是能单独搭出一切逻辑的最小单元。

## 为什么存在

逻辑上它是「与 + 非」；物理上它才是原生的反相型门（4 管），而「与门」是它再接一个非门（6 管）。所以工程上真正当最小砖头的，是它而不是与门。

## 为什么它单独就够搭出一切

用 NAND 就能变出非、与、或：

- 非 x = NAND(x, x)
- a 与 b = 非(NAND(a,b))
- a 或 b = 非(非 a 与 非 b)

既然非、与、或能搭出任何表，NAND 单枪匹马也就能搭出一切。同理「或非门（NOR）」也行。

## 物理层（为何原生）

- 「输出 0」要两输入都 1 → 两个 N 管串联，天然匹配；
- 「输出 1」要任一为 0 → 两个 P 管并联，天然匹配。

4 管直接成型，无需反相；「与」「或」反而要额外加反相器。

## 速度：它是最快的一档

4 管结构正好把「快」的方向都占了：下拉用 N 管串联（N 管电流能力强，串两个也扛得住），上拉用 P 管并联（任一条通就行）。

对比它的镜像——或非门：下拉 N 管并联同样快，但上拉要 P 管串联，而 P 管本就比 N 管弱，串起来更慢。所以同样 4 管，或非门通常比与非门慢，CMOS 工艺因此偏爱与非门。

也别忘了与门：它是与非门再串一个非门，多一次充放电，约慢一倍。

这里讲的是「与非门 4 管」这件事的第三个后果：物理上最省（比与门少 2 管）、逻辑上完备（能搭出一切）、速度上最快。详见 [[电路时延]]。
